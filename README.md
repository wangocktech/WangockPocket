# Wangock Pocket

Портфолио в виде портативной консоли с двумя встроенными играми: «Змейка» и «Тетрис». На странице только ровно стоящий Game Boy. Экран отображает содержимое; управление — исключительно кнопками корпуса или клавиатурой. HTML, CSS и JavaScript без зависимостей и сборки. Шрифты хранятся на сервере.

## Запуск

Node.js 18 или новее:

```sh
node scripts/serve.mjs
```

Открыть http://127.0.0.1:4173. Другой порт: `PORT=8080 node scripts/serve.mjs` (PowerShell: `$env:PORT=8080; node scripts/serve.mjs`). Можно использовать любой сервер статических файлов; через `file://` модули браузера не загрузятся.

## Управление

| Действие | На консоли | Клавиатура |
| --- | --- | --- |
| Включить | START или переключатель OFF/ON | Enter / пробел / P |
| Выбрать пункт | Крестовина | Стрелки |
| Открыть | A | A / Enter / пробел |
| Назад | B | B / Esc / Backspace |
| Главное меню | SELECT | Tab до SELECT, затем Enter |
| Перелистывать «Обо мне» | Крестовина / A | Стрелки / A |
| Прокрутить подробности | Вверх / вниз | Стрелки |
| Змейка | Крестовина — направление, B — пауза | Стрелки, B / Esc — пауза |
| Тетрис | Влево/вправо — двигать, вниз — ускорить, вверх/A — повернуть, B — пауза | Стрелки, A / Enter, B / Esc |
| Продолжить / начать заново игру | A или START | A / Enter / пробел |
| Выключить | Переключатель OFF/ON | P |
| Включить/выключить звук | Кнопка SOUND на корпусе | M |

Игры находятся в разделе «АРКАДА». SELECT завершает текущую сессию и возвращает в главное меню. Tab и Shift+Tab перемещают фокус только по физическим кнопкам. Экран не реагирует на нажатия, касания, свайпы или прокрутку колёсиком. Telegram открывается кнопкой A после выбора соответствующего пункта. Масштабирование страницы не запрещено. Звук по умолчанию выключен, настройка сохраняется в браузере. Учитывается системное уменьшение анимации.

## Замена содержимого

Всё содержимое экрана находится в `content.js`:

- `name`, `role`, `about` — имя, специализация и текст «Обо мне».
- `telegram`, `handle` — ссылка и имя пользователя Telegram.
- `projects` — проекты, описания, технологии и возможности.
- `services`, `pricingNote` — услуги, цены и сроки.

У каждого проекта `isDemo: true` показывает отметку «ДЕМО». Укажите реальные `demoUrl` и `sourceUrl`, чтобы появились ссылки на сайт и исходный код. При `demoUrl: null` открывается встроенный обзор; неработающих ссылок-заглушек нет. `art` выбирает пиксельную иллюстрацию: `orbit`, `forma` или `pixel`. Проекты — демонстрационные концепты, цены — примеры, а не заявленные реальные работы или фиксированная оферта.

Разметка корпуса и метаданные находятся в `index.html`, внешний вид — в `styles.css`. В `app.js` — отрисовка экрана и обработка ввода. `navigation.js` отвечает за стек экранов и восстановление выбранного пункта при возврате. `games.js` — чистая логика Snake и Tetris: игровое поле, столкновения, фигуры, линии, счёт и пауза.

`sound.js` проигрывает короткие WAV-файлы через нативные аудиоэлементы, без AudioContext. Вызов воспроизведения остаётся непосредственно в обработчике нажатия для совместимости с Safari и встроенными браузерами iOS. Выключение SOUND и уход со страницы останавливают текущий звук; возврат ждёт следующего нажатия. Если браузер отклоняет воспроизведение, индикатор выключается и экран предлагает повторить нажатие SOUND. Оригинальные звуки хранятся в `assets/sounds/`; их можно пересоздать командой `node scripts/generate-sounds.mjs`. Стрелки крестовины и экрана — SVG, а не символы, которые iOS может отобразить как эмодзи.

## Проверка

```sh
node --check app.js
node --check content.js
node --check sound.js
node --check games.js
node --test tests/navigation.test.mjs
node --test tests/games.test.mjs
```

Браузерная проверка на VPS: `/opt/wangock-checks/bin/python tests/browser_check.py`.
Она проходит разделы, Snake и Tetris с клавиатуры и через `tap()` с включённой эмуляцией касаний, проверяет смешанный ввод, Tab, звук, копирование и ширины 320–1440 px. По умолчанию используется Chromium; для WebKit укажите `PORTFOLIO_BROWSER=webkit`. Скриншоты и JSON-отчёт сохраняются вне сайта: `/tmp/wangock-browser-results`.

Быстрая изолированная проверка игр в Chromium и WebKit: `/opt/wangock-checks/bin/python tests/games_browser_check.py`. Она запускает обе игры клавиатурой и touch-кнопками, проверяет паузу, поворот Tetris и возврат через SELECT.

Проверка звука в обоих движках: `/opt/wangock-checks/bin/python tests/audio_check.py`. Она проверяет реальные WAV-файлы, завершение их воспроизведения от касаний и клавиатуры, быстрые повторные нажатия, выключение, сохранение настройки, уход/возврат и повтор после отказа браузера. Эмуляция жизненного цикла страницы не заменяет проверку динамика на физическом iPhone. Артефакты: `/tmp/wangock-audio-results`. Оба сценария принимают `PORTFOLIO_URL` и `PORTFOLIO_RESULTS` для проверки отдельного релиза.

## VPS

Публичный адрес: https://wangock.tech

- Веб-сервер: Nginx, автозапуск через systemd.
- Файлы: `/var/www/wangock/releases/`.
- Активный релиз: `/var/www/wangock/current` (символическая ссылка).
- Конфигурация: `/etc/nginx/sites-available/wangock`, образец — `scripts/nginx.conf`.
- Проверить: `nginx -t`, `systemctl status nginx`, `curl -I http://127.0.0.1`.

Для обновления загрузите новый релиз в отдельный каталог, выполните проверки и переключите `current`. Сборка и постоянно работающий Node.js для сайта не нужны.

HTTPS: сертификат Let's Encrypt для `wangock.tech`, автоматическое продление через `certbot.timer`. Проверка продления: `certbot renew --dry-run`. Nginx перенаправляет HTTP на HTTPS. DNS A-запись домена должна оставаться `186.246.9.50`.

Пароли и SSH-ключи в проекте не хранятся.
